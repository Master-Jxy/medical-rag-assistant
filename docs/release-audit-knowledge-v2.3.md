# Knowledge v2.3 发布审计

## 范围

阶段12新增回答质量闭环、用户可控记忆、复杂文档解析质量、引用追溯和知识治理，
不改变冻结检索基线、普通RAG Prompt、Agent工具白名单或生产Chroma内容。

## 能力与边界

- `0013`至`0017`新增回答反馈、滚动摘要、显式记忆、解析质量、引用标识和治理字段。
- 用户只能反馈自己的已完成回答；管理员只读取聚合和有长度上限的复核摘录。
- 最近3轮优先保留，较早会话使用提取式摘要；长期记忆默认关闭并由用户显式CRUD。
- PDF逐页显示文本、疑似表格和扫描/图片风险；质量检查失败不会进入审核。
- Docling/OCR只登记为可选候选，当前未安装、未晋级，生产继续使用PyPDF。
- 引用保存文档与切片ID，认证用户可打开已发布原文及PDF页码，并查看版本和来源。
- 知识资产支持分类、科室、失效和复核周期；到期扫描及复核完成都通过`JobPort`维护任务。

- 后端完整测试：320项通过。
- 前端完整测试：10个文件、33项通过。
- 普通聊天SSE UTF-8分片和Vite正式构建通过。
- SQLite从空库升级和回滚路径通过；真实MySQL从`0012`升级到单一
  `0017_knowledge_governance (head)`。
- MySQL升级前后文档、已发布文档和提交均为27；固定语料清单为27份文档、103个
  Chroma片段，状态`passed_with_warnings`。
- 1280真实浏览器验收个人记忆、回答反馈、引用追溯、质量趋势/复核、解析审核、
  资产治理和任务中心，关键页面整页横向溢出为0且控制台无错误。
- 浏览器运行面板本轮不能动态切换390视口，因此不把390写成已完成真实浏览器证据；
  页面保留移动端媒体查询，部署后继续检查可用视口。

## 成本与清理

阶段12没有调用Embedding、Qwen、Reranker、Docling或OCR，模型费用为0。浏览器验收
使用的临时账号、会话、反馈和记忆均已删除；文档和Chroma未写入或删除。
