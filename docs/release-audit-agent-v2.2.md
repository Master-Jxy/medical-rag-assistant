# Agent v2.2 发布审计

## 范围

阶段11新增独立的受控资料Agent，不替换普通RAG。Agent只读取`published/ready`公共
知识，提供检索、文档信息、摘要、比较和学习报告五个白名单工具；不开放网页、代码、
SQL、系统命令、诊断、处方、多Agent或任意插件。

## 安全与一致性

- `0012_agent_persistence`新增按用户隔离的运行、步骤和产物表。
- LangGraph最多5个工具步骤，默认单工具30秒、整次120秒，检查Token、费用和主动停止。
- 工具只依赖公开Port；Agent工具静态测试禁止导入Repository、SQLAlchemy、Chroma、
  Redis、DashScope SDK或系统命令。
- 明确文档ID的摘要、比较、报告走确定性白名单路由；禁区任务确定性拒绝，模糊任务才由
  LangChain规划。数据库不保存隐藏推理过程。
- Agent使用独立REST、SSE、页面和解析器；普通聊天接口及SSE契约未修改。

## 发布边界

功能开关默认关闭。只有部署环境显式设置`AGENT_ENABLED=true`且模型、数据库、Chroma
配置完整时才允许创建新运行；历史查询和普通RAG不因Agent关闭或初始化失败而受影响。
